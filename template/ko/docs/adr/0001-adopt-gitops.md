## 결정

결정마다 출처를 괄호로 적는다. "승인자 제시"는 승인자가 직접 말한 것, "승인자 선택"은 에이전트가 낸 선택지에서 승인자가 고른 것이다. 에이전트가 정한 것은 "에이전트가 정함"으로 따로 적는다.

1. 목적은 에이전트에게 맡긴 작업을 승인자가 안심하고 받아들이거나 되돌릴 수 있게 하는 것이다. 기록·판정 지점·되돌림 세 가지만 갖춘다. 막는 대상은 협조하는 에이전트의 실수다([GIT.md](../GIT.md) '목적과 범위').
2. 승인자는 판정용 PR 본문과, 작성자가 아닌 새 맥락의 독립 검수 결과로 PR을 판정한다.
3. 위험 등급은 바뀐 파일 경로로 정하고, 섞이면 가장 높은 등급을 따른다(GIT.md '위험 등급').
4. 모든 PR은 사람이 병합한다. 에이전트는 병합하지 않는다.
5. 보호 브랜치는 `gitops.config.json`의 `protectedBranches`로 정한다.

## 버린 대안

- 모든 PR을 에이전트가 병합: 작성자와 같은 계열의 판단만 남아 체계적인 착오를 잡을 수 없다.
- 등급을 에이전트가 판단: 세션마다 답이 달라진다. 경로 규칙은 누구나 같은 답을 얻는다.
- 에이전트 병합 위임: GIT.md '넣지 않은 장치와 다시 필요해지는 조건'.

## 결과와 위험

- 승인자는 모든 PR의 병합 버튼을 누른다. 저위험은 본문 두 칸만 본다.
- 경로 규칙은 내용을 보지 않는다. 저위험 경로의 위험한 내용은 독립 검수가 걸러야 한다.
- 로컬 장치는 우회할 수 있다(GIT.md '장치와 한계').

## 재검토 조건

서버 보호를 쓸 수 있게 됨, 승인자 추가, 저위험 PR 판정이 실제 부담이 됨(→ GIT.md '넣지 않은 장치와 다시 필요해지는 조건').
